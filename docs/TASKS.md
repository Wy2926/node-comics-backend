# 任务与额度

## 单图

- 客户端冻结 UUID、输入摘要、语言、模型与字体；未知结果查询原请求。
- API 持久化任务，节点处理图像，control-worker 调用文本模型，maintenance 恢复与清理。
- 租约绑定身份、代次和截止；终态回执稳定，同一任务只结算一次。
- 原图在中心共享磁盘保留至任务结束后默认 24 小时，所有用户统一读取后台系统设置 `image_input_retention_hours`。注册账户译图默认保留 7 天，由 `image_result_retention_days` 调整；游客译图保留 24 小时。后台任务详情可按需查看原图与完整译图；覆盖层预览依赖原图，历史已清理图片不可恢复。最后一个有效请求删除后回收原图与译图，活跃任务的原图在结束后回收。
- 上传校验与落盘在短事务外执行，最终提交复核租约；持久交付可恢复，不能重复调用供应商。

## PDF / ZIP / CBZ

- 浏览器直传私有 R2，API 不解析或代理大文件。document-worker 只处理文本。
- 同一计算宿主完成解析、OCR、渲染和 ZIP；中间产物只在节点持久工作目录。
- 全部 OCR 完成后中央汇总一次 LLM；发送前保存意图，结果未知保留预占并待核实，禁止盲目重发。
- 源文件一次下载，最终 ZIP 一次上传；阶段回执幂等，校验任务、宿主、租约和目录双代次。
- 节点失盘不能把 sending/unknown 当失败重试；旧协议文档任务先排空再迁移。
- 文件预算、功能开关、R2 生命周期和 CORS 在配置中声明；签名仅用于精确对象，不进日志。

## 账户与付款

- 用户额度、供应商成本分账；失败释放用户预占不抹去已发生的成本。
- 套餐、期限会员、赠送与额度包使用持久账本；月度发放保持原账期锚点。
- 结账请求键和 webhook 事件幂等，校验签名与支付环境；返回页不发权益。
- 回执丢失恢复原订单，不能自动创建第二笔付款；身份、任务、访问与权益按用户隔离。

数据结构见 `backend/app/models.py`、`queue_models.py` 和各领域模块；公开结构见 [OpenAPI](../contracts/README.md)。关键回归位于 `backend/tests/test_compute_*`、`test_document_*` 和支付/额度测试。
