# 任务与额度

组件职责、调度与执行流程见[任务执行架构](ARCHITECTURE.md)；本文维护持久性、保留与结算规则。

## 单图

- 客户端冻结 UUID、输入摘要、语言、模型与字体；未知结果查询原请求。
- 单页全部 OCR 文本一次请求；仅完整译文可复用，部分检查点整页重译并整体替换。明确失败按持久重试时间重新调度，退避不占文本执行位；已发送但结果未知时保留预占待核实。
- 单页和整本只提交 OCR 正文，不传文件名。旧请求里的 `comic_title` 直接忽略，不参与缓存、幂等或提示词。正文模型需支持严格 JSON Schema；新版单页遇到译文校验失败或响应截断时，按错误码补一句纠正要求，不回传上次答复。
- 租约绑定身份、代次和截止；终态回执稳定，同一任务只结算一次。
- 原图在中心共享磁盘保留至任务结束后默认 24 小时，所有用户统一读取后台系统设置 `image_input_retention_hours`。注册账户译图默认保留 7 天，由 `image_result_retention_days` 调整；游客译图保留 24 小时。后台任务详情可按需查看原图与完整译图；覆盖层预览依赖原图，历史已清理图片不可恢复。最后一个有效请求删除后回收原图与译图，活跃任务的原图在结束后回收。
- 上传校验与落盘在短事务外执行，最终提交复核租约；持久交付可恢复，不能重复调用供应商。

## PDF / ZIP / CBZ

- 生效的订阅、预付、试用、赠送会员，或至少一个已生效且有未预占余额的购买页数包，均可创建整本任务。3500／7000 页包按购买时的 PLUS 服务档位生效，不需要订阅。仅有每日免费额度或赠送页数不能解锁。整本受理走付费队列，解析后仍按实际页数和模型分别预占、结算。
- 资格只在新建时判定。两类权益均无时沿用 `403 DOCUMENT_MEMBERSHIP_REQUIRED`，不会创建任务或上传。`/v1/documents/capabilities` 此时返回 `enabled: false`、`unavailable_reason: "membership_required"` 和空模型列表；全站关闭时原因为 `null`。已受理的编号可重放、继续处理和取回结果，仍按原规则预占及结算。
- 注册账户的首次单图、整本上传不占全局调度锁；单图在账户锁内预占，整本查模型范围，核实页数后再一次预占。进入可执行队列时才唤醒调度。
- 全部 OCR 完成后中央汇总一次 LLM；发送前保存意图，结果未知保留预占并待核实，禁止盲目重发。
- 源文件一次下载，最终 ZIP 一次上传；阶段回执幂等，校验任务、宿主、租约和目录双代次。
- 节点失盘不能把 sending/unknown 当失败重试。
- 文件预算、功能开关、R2 生命周期和 CORS 在配置中声明；签名仅用于精确对象，不进日志。

## 账户与付款

- 用户额度、供应商成本分账；失败释放用户预占不抹去已发生的成本。
- 模型 `quota_multiplier` 独立于套餐权限、分流权重、供应商 token 单价，默认 1，范围 0.0001–10000，最多 4 位小数。计费额度 = 计费页数 × 任务创建时冻结的倍率；调价不改变在途任务或缓存身份。免费模型优先免费额度，再使用匹配的付费额度；付费模型不能扣免费额度。游客仍按体验次数限流，不扣账户额度；无限权益仍不扣有限额度。
- 余额、预占、结算与账本使用四位定点小数，API 返回 JSON number；赠送及周期补偿可发放小数额度。每页从一个可支付完整该页费用的桶扣取，跳过不足一页的余额；整本文档按页跨桶分配，全额预占成功后开始处理，仅结算成功且可计费页，其余按冻结倍率释放。
- 单图与整本都按原权益版本的服务档位匹配模型，也可指定仅售页数包的产品 ID；与会员档位重名时只认服务档位。显式选模不替换；自动选模沿用可用的原加权结果，否则从可支付的模型中选择。整本模型有权限但余额不足时，仍可预检后等待补额。
- `/v1/capabilities` 的 `translation_models`、`/v1/documents/capabilities` 的 `models` 返回 `quota_multiplier`、`requires_paid`，按倍率升序，同倍率按创建时间、ID 升序。单图回执返回冻结的 `quota_multiplier`、`quota_pages`、`quota_kind`、`settlement`；文件回执返回冻结倍率及额度单位的 `quota`，`page_count` 始终是物理页数。旧 `*_pages` 额度字段允许小数，前端不要取整。
- 套餐、期限会员、赠送与额度包使用持久账本；月度发放保持原账期锚点。
- 结账请求键和 webhook 事件幂等，校验签名与支付环境；返回页不发权益。
- 回执丢失恢复原订单，不能自动创建第二笔付款；身份、任务、访问与权益按用户隔离。

数据结构见 `backend/app/models.py`、`queue_models.py` 和各领域模块；公开结构见 [OpenAPI](../contracts/README.md)。关键回归位于 `backend/tests/test_compute_*`、`test_document_*` 和支付/额度测试。
