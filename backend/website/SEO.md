# 搜索与内容

- 每页一个主要用途，标题、H1、正文与 FAQ 一致，不堆关键词或虚构排名。
- 公开页面维护 canonical、hreflang、sitemap 与结构化数据，17 语路径对应；语言由 URL 决定。
- 首页介绍产品，下载页安装，定价页报价，指南页操作；实际商店与平台状态来自数据模块。
- 账户、回调、支付返回、卸载反馈和翻译工作台 noindex；私有页面 no-store。
- 站点目录只介绍支持能力；外链与漫画版权明确，不暗示合作或授权。
- `npm run build` 检查站内链接、锚点、商店入口及 FAQ 数据。

IndexNow 通知：根目录 `python scripts/submit_indexnow.py <公开URL>` 先检查，加 `--submit` 才发送；仅提交实质变更页面。
